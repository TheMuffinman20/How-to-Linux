# Finalization

Now that we have set all the options correctly, we can start the installation. Wait until it is complete, do not disconnect the internet connection, and do not turn off the computer.

The duration of the installation varies by computer and distribution. Choose `Restart` (or the equivalent option) if the installer asks. Remove the USB stick only after the screen is completely **empty** and **black** and the computer has restarted.

## Complete the installation

Linux is now installed. In a dual-boot setup, the computer usually shows a **boot menu** where you can choose Linux or Windows. If that menu does not appear, go to the **BIOS/UEFI** of your computer and check whether the correct boot option is selected.

If you installed Linux as your only main operating system, the computer starts directly in Linux.

## First startup

In **dual boot**, the computer usually shows a **boot menu** where you choose Linux or Windows. If that menu does not appear, go to the **BIOS/UEFI** and check whether the correct boot option is at the top.

In **single boot**, the computer starts directly in Linux.
