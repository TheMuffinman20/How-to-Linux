## About this repository

View in [**Dutch**](README.md)

Welcome to How-to-Linux! This repository contains a comprehensive guide for installing Linux, both as a single-boot installation and as a dual-boot setup alongside an existing operating system.

> [!WARNING]
> Always make a backup before you begin the guide.

## Quick start

1. Back up your data.
2. Follow the installation guide carefully.
3. Choose the distribution you want to use.
4. Choose the desktop environment that suits you.
5. Choose the bootloader according to your operating systems.
