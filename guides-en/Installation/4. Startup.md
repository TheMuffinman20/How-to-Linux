# Booting

Now that you have placed the Linux ISO on a USB stick and prepared your system, it is time to actually start the computer from that stick. In this chapter, you go to the BIOS/UEFI, change the boot order, and check whether Secure Boot may need to be disabled. Only if these steps are done correctly can the Linux live environment start properly and you can continue with the actual installation.

## Open BIOS/UEFI

To start from the USB stick, you need to access the **BIOS/UEFI**, the settings menu of your computer. The exact steps differ per computer.

- **UEFI** is the newer standard
- **BIOS** is the older variant

Follow these steps to open the **BIOS/UEFI**:

1. Leave the USB stick connected and restart the computer.
2. During startup, open the boot menu by pressing the **BIOS/UEFI** key.
3. Go to the **Boot** tab.
4. Move the **USB stick** to the top of the boot order, before the **Windows Boot Manager**. Prefer the entry that begins with **UEFI**.

> [!NOTE]
> The **BIOS/UEFI** key differs by motherboard manufacturer, but it is often **F2, F12, F11, F8, Esc**, or **Del**. Sometimes you can see this during startup in a brief message, but you can also look it up if you know the brand of your motherboard or computer.

## Secure Boot

**Secure Boot** ensures that a computer only boots from software with an approved signature. Many Linux distributions do not have this by default, which causes the USB stick to be rejected.

> [!IMPORTANT]
> Secure Boot does not need to be disabled for every Linux distribution. Only disable it if the documentation of your chosen distribution states this, or if booting otherwise fails. If you are not sure, check the official installation steps for your distro first.

1. In the BIOS/UEFI, go to the **Security** menu (sometimes it is under **Boot**).
2. Find **Secure Boot** and turn it **off**.
3. Save with **F10** (or **Save Changes & Exit**).

> [!WARNING]
> Some games with kernel-level anti-cheat (for example Valorant) refuse to start in Windows if Secure Boot is off. If you want to play those games, turn Secure Boot back on after installation if your distro allows it.

## Live environment

After saving, the computer starts from the USB stick. You will see a boot menu where you can choose which version of your distro to start.

- The default option usually matches your distro, for example **CachyOS**.
- Sometimes there is also an **LTS** option, which is the stable version of the kernel.

> [!TIP]
> **LTS** stands for _Long Term Support_ and means that a version receives updates for a longer period. These versions of the operating system are ideal for servers and for users who want a stable, long-term supported installation.

Choose the default option. You will then enter a **temporary Linux environment** in which you can try the distro or continue with the final installation.
