# Setup

In this chapter, you choose a distribution that matches your system and preferences, download the correct ISO, and place it on a USB stick so you can safely boot into a live environment later. These preparations ensure a smoother installation and reduce the chance of running into small problems later.

## Download the ISO

Before we can begin the actual installation, you first choose which distro you want to use or test. You download it as an **ISO** file.

Follow the steps below:

1. Go to the official website, for example: https://cachyos.org/download/
2. Download the correct ISO for your processor type **(x86/ARM)**
3. Check the **checksum** of the file if the website provides one. This ensures the download was not corrupted.

> [!TIP]
> Unsure about this choice? Then check the workshop on [**Distributions**](../Distributies/Distributies.md).

## Download a helper tool

To place a Linux ISO on a USB stick, we need a special helper tool. An **ISO** file cannot simply be copied; it must be correctly “flashed” so the **USB** stick can use it as a bootable medium.

Below are three commonly used tools, each with its own strengths and target audience.

### BalenaEtcher

BalenaEtcher is available for **Windows, macOS, and Linux**, making it a popular choice. The program stands out for its simplicity: you select the **ISO**, choose your USB stick, and **Balena** handles the rest. The interface is clear and works well for beginners.

1. Go to the official website: https://etcher.balena.io/
2. Download the latest version

### Rufus

**Rufus** is the tool we will use in this workshop. It is an excellent all-rounder: fast, reliable, and equipped with extra options that are helpful when installing Linux in different situations.

1. Go to the official website: https://rufus.ie/en/#download
2. Download the latest version for your processor type **(x86/ARM)**

### Ventoy

**Ventoy** is the most advanced program on this list. Instead of flashing a USB stick each time, Ventoy creates a special environment in which you can simply copy **ISO** files and later choose which distro you want to boot. This works well if you want to test multiple Linux versions on one stick.

1. Go to the official website: https://www.ventoy.net/en/download.html
2. Download the latest version for your processor type **(x86/ARM)**

## Flash the USB drive

First, insert the USB stick you want to use into your computer. Check that there are no important files on it, because during flashing the entire contents are permanently erased. Then open the helper tool you downloaded.

Follow these steps in Rufus:

1. Select the USB stick you want to flash under `Device`
2. Click `SELECT` and choose the **ISO**
3. Select `GPT` as the partition scheme
4. Check that the target system is set to `UEFI (non-CSM)`
5. Ignore the size of the persistent partition, the volume label, and the cluster size

Check one last time that you selected the correct **USB** stick before starting the flash process. Also make sure all settings match the ones described above.

6. Click `START`

Wait until the tool finishes writing the file. After that, you can safely remove the USB stick from the computer. You have now created a so-called **Live USB**!

> [!TIP]
> Do you want to use the stick as normal storage later? Right-click it in Windows Explorer and choose `Format`.
