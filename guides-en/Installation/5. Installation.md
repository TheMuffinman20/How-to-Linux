# Installation

Now that the computer has successfully started from the USB stick, it is time for the actual installation. In this phase, you load the Linux live environment, choose the correct language and settings, and let the installer configure the partitions and bootloader. If these steps are done correctly, you will have a working Linux installation that can boot directly within a short time.

The installer usually starts automatically in the live environment of your Linux distribution. If it does not, choose the Linux boot menu option **Try or Install Linux** (or the equivalent option for your distribution).

Follow the installer instructions:

1. Connect to the internet via WiFi or Ethernet
2. Choose your preferred language for the system
3. Choose the region and time zone
4. Choose the correct keyboard layout

## Bootloader

The bootloader is the program that starts before the operating system to let you choose which OS you want to run on the computer. There are usually many different bootloaders, each with its own way of working and its own preference for different systems.

In this guide, we will choose **Limine**, a simple but fast bootloader.

> [!TIP]
> Unsure about this choice? Then check the workshop on [**Bootloaders**](../Bootloaders/Bootloaders.md).

## Partitions

There are several choices when it comes to disk or partition layout. Depending on your use case, we can choose the right option. Choose one of the options below to continue for your situation.

### Dual boot (Linux alongside Windows)

If the installer detects Windows, choose **Install Linux alongside Windows**.

If that option is not available or the installer gives an error, you may be able to choose **Something else** or **Manual Partitioning** to configure the partitions manually.

#### Manual partitioning

**1. Boot partition (EFI)**

The first partition is reserved for the bootloader and is essential for any operating system that wants to use dual-boot. This is where the program that starts with the computer is placed. This partition is needed so the computer knows which operating system settings to load.

1. Select the **Unallocated space** you created in Windows.
2. Click **Create**
3. Set the size to **4096 MB**
4. Choose **FAT32** as the file system
5. Set the mount point to **/boot**
6. Enable the **boot** flag

**2. Main partition**

This is where Linux itself will be installed, along with all your files.

1. Select the **Unallocated space** again. The previous size should now be reduced by 4 GB.
2. Click **Create**
3. Leave the file system as **Btrfs**
4. Mount this partition by entering **/**
5. Do not enable any flags

Check your choices carefully and then confirm the installation.

### Single boot (Linux only)

Choose **Erase disk and install Linux** if you want Linux to be the only operating system on the selected disk.

> [!CAUTION]
> This option deletes all data on the selected disk, including Windows and personal files. Check carefully which disk is selected and make a backup beforehand.
