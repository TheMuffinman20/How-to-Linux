# Preparation

In this chapter, you check whether Windows is accidentally blocking the installation, disable security features such as BitLocker, and free up the correct space on your disk. These steps may seem small, but they prevent frustrating problems later, such as a blocked boot, lost installation options, or a Windows system that no longer starts normally.

> [!NOTE]
> If you choose **single boot** (Linux only), then you only need to follow the section on [BitLocker](#disable-bitlocker) if Windows is still installed on the disk.

## Disable BitLocker

BitLocker is a Windows security feature that can encrypt your system partition. If BitLocker detects a change in the boot environment, such as using a different disk or a different boot order, it may prevent the boot or ask for a recovery key.

Disable it first, even before shrinking the partition.

**Windows Home** (*Device encryption*):

1. Open **Settings** → **Privacy & security** → **Device encryption**
2. Toggle the switch off

**Windows Pro** (*BitLocker drive encryption*):

1. Search the Start menu for **BitLocker Manager**
2. Click **Turn off BitLocker** for your C: drive

Disabling BitLocker may take some time depending on the size of your disk, but you can continue using the device in the meantime.

### Did you forget to disable BitLocker?

No panic. If BitLocker is activated during startup, Windows will ask for a recovery key. You can find it as follows:

1. Go to https://account.microsoft.com/devices/recoverykey
2. Log in with the same Microsoft account you use on the computer
3. Find the recovery key that matches your device
4. Enter the code on the computer

After that, you can deactivate BitLocker and continue with the installation.

## Disable Fast Startup

Windows has a feature called *Fast Startup*, where shutting down is essentially a kind of sleep state. This leaves your Windows disk “locked”, and Linux may not be able to access it properly.

1. Search the Start menu for **Control Panel** → **Power Options**
2. Click **Choose what the power buttons do**
3. Click **Change settings that are currently unavailable**
4. Uncheck **Turn on fast startup**
5. Click **Save changes** and then fully shut down Windows

## Free up disk space

### Dual boot

When you want to install Linux alongside Windows, you first need to create free space on your hard drive or SSD. We do this by shrinking the existing Windows partition so there is room for Linux.

Follow these steps:

1. Search the Start menu for **Disk Management** (**Create and format hard disk partitions**)
2. Right-click the main partition at the top (usually the C: drive)
3. Choose **Shrink Volume**
4. Specify how much space you want to allocate to Linux
   - Minimum 50 GB
   - 100 GB or more is recommended
5. Click **Shrink**

A block of **Unallocated space** will now appear. You do not need to create a new partition here; Linux will arrange it correctly during installation.

### Single boot

If you choose to install Linux only, you do not need to free up space in Windows. During the Linux installation, you can choose to use the entire disk.

> [!CAUTION]
> This option permanently deletes all Windows data!

If you later want to reinstall Windows, you should know that Windows tends to overwrite the bootloader. In practice, you therefore install:

1. Windows first
2. Linux second

For single-boot this does not matter, but for dual-boot the order is important.

You now have a **Live USB** containing the Linux **ISO**, and a section of unallocated space on your disk where Linux can be installed.
