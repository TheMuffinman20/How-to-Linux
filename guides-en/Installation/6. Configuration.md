# Configuration

The base installation is now complete, and the system is ready to become more personal. In this chapter, you choose how Linux looks for you, which packages you need immediately, and how best to configure your user account and settings. These choices greatly influence your daily experience with the desktop, so it is wise to think carefully here.

## Desktop environment

Some installers ask which desktop environment you want to use. That is what you see after logging in: the desktop, taskbar, menus, and windows. You can change this later.

In this guide, we will choose **KDE Plasma**.

You can also choose **Hyprland**, a Wayland-based window manager that offers a flexible environment and higher speed compared to some other desktop environments.

If you choose **Hyprland**, the desktop environment will start with **Noctalia Shell**. If you still want **Caelestia Shell**, choose **No Desktop** here and then follow the guide on [**Caelestia**](Caelestia.md) after the final step of this installation.

> [!WARNING]
> You will not have a desktop environment when you log in to the computer; only a TTY will be available so you can install your environment yourself.

> [!TIP]
> Unsure about this choice? Follow the guide on [**Desktops**](../Desktops/Desktops.md).

## Packages

You will also get a menu with useful packages to install before setup is finished. Some packages you may consider:

- HP Printer Support
- General Printer Support
- Accessibility tools (screenreader, mouse tweaks)

## Users

Finally, the installer will ask which user will manage the system. Several pieces of information are needed for this, which you can follow below:

1. Enter your full name
2. Enter your username
3. Enter the name of the computer
4. Enter the password for the user

> [!TIP]
> If you want to use the same password for root, select the option **Use the same password for root**.
